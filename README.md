### Instrucciones para ejecución de la página web:

1. Clonarlo desde el repositorio GitHub
2. ```cd proyecto-web```
3. ```npm install```
4. ```npm install react-router-dom```
5. ```npm install tailwindcss @tailwindcss/vite```
6. ```npm install cypress --save-dev```
7. ```npm run dev```
8. ```npx cypress open```
